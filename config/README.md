# OpenVPN-Install Configuration Templates

This directory contains configuration templates and examples for OpenVPN-Install.

## Files

- `server-config-example.conf` - Example OpenVPN server configuration
- `client-template-example.conf` - Example client configuration template

## Usage

These templates are automatically generated by the installer. You can reference them for:
- Understanding the configuration
- Manual modifications
- Backup and documentation
- Custom setups

## Important Notes

Do not manually edit `/etc/openvpn/server.conf` unless you know what you're doing.
The installer handles all configuration automatically.
